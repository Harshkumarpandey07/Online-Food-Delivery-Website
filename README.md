🍽 FreshBite – Simple Online Food Delivery Website

FreshBite is a clean and user-friendly online food delivery website built using HTML, CSS, and minimal JavaScript.
It provides a smooth browsing experience where users can explore food items, add them to the cart, and proceed to checkout — all in a simple and responsive layout.

🚀 Features

🧑‍🍳 Simple Menu Layout: Display of popular dishes with prices and images.

🛒 Add to Cart Functionality: Users can easily add multiple items to their cart.

💳 Checkout Option: A minimal checkout alert that confirms the order.

📱 Responsive Design: Works smoothly on desktop and mobile screens.

🎨 Lightweight and Fast: Uses plain HTML, CSS, and just a few lines of JS.

🧱 Tech Stack

HTML5 – Structure and content

CSS3 – Styling and layout (fully responsive)

JavaScript (Vanilla) – Handles add-to-cart and checkout logic
